Open index.html in Chrome, Edge or Safari with all files kept together. For reliable browser document storage, host the unzipped folder on HTTPS. The current live Saarthi URL has NOT been updated by this package.

MY PORTFOLIO
- Overview: indicative consolidated portfolio equity XIRR, attributable capital, debt, cash plan and alerts.
- Assets: individual equity XIRR shown for each property alongside value, debt and decision.
- IRR & returns: portfolio XIRR, all-asset IRR distribution, export, editable acquisition date, invested equity and annual distribution assumptions.
- Documents: searchable document index and asset folders. Upload PDF/images through each property's Documents tab. Uses browser IndexedDB, not cloud storage.
- Asset services: linked service requests and a local self-tracked status register; no service provider is contacted.
- Risk: expanded visual risk command centre with exposure charts, six risk lenses, concentration, ranked actions, technical records and a downloadable HTML report (open HTML and print/save PDF).
- Individual asset record: Overview, Valuation, IRR, Technical details, Documents, Services & decisions.

IRR METHODOLOGY
- Dated XIRR of an initial equity investment, assumed annual interim cash distributions and current marked equity as a terminal cash flow.
- Consolidated portfolio XIRR combines the dated cash flows across all properties. This is not the arithmetic average of asset IRRs.
- Original eight demonstration properties have explicitly illustrative investment-basis and distribution assumptions, which can be edited.
- The model does not automatically capture historical acquisitions, disposals, capital calls, taxes, stamp duty, financing changes or actual dated distributions. For institutional reporting these need to be entered as a dated transaction ledger; therefore returns shown here are INDICATIVE, not audited or realised.
- Operating premises and family-use assets may have a capital return but their nonfinancial benefits are not included.

RISK & TECHNICAL INFORMATION
- Technical details are editable per property: survey/CTS, area and units, zoning, FSI/FAR, title, approvals, micro-market/coordinates, access and constraints.
- Empty or unverified technical fields are shown as such. No land records, GIS, statutory permissions or independent valuations are connected.
- Risk flags are rule-based and not a validated probability-of-loss model. Detailed report is an HTML download suitable for printing to PDF.

SECURITY / PROTOTYPE LIMITATIONS
- Data is demonstration data. Do not upload confidential client documents to this prototype.
- Asset document files are stored locally in the current browser (IndexedDB). Return assumptions and technical metadata are stored in localStorage. Existing CIO portfolio editing is session-only.
- There is no authentication, server-side document repository, encryption at rest, multi-user permissioning, audit log, advisor workflow backend or live market data.
- For production, use an approved access-controlled storage system, a transaction-level performance ledger, audited valuations and verified land/property records.
