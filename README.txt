Architectural imagery and interactive portfolio tools
8 October 2026

OPEN
Extract the complete folder, then open index.html on a computer.
Keep the assets, reports and route folders beside index.html.
On iPhone or iPad, use the hosted website in Safari:
https://saarthi-private-desk.aneeshsoman194.chatgpt.site
The iOS Files preview does not run this website reliably.

OPPORTUNITIES
Use the category buttons, search and filters to find opportunities.
Three entries appear initially; Show more reveals the next three.
View details opens a full-screen opportunity dossier with its image,
terms, brief download, save control and enquiry draft form.
The table view, three-way comparison and saved-opportunity list remain available.

MY PORTFOLIO
Overview, Assets, Cash flow, Scenarios and Risk share the same holdings.
Use Explore portfolio for the full-screen asset, purpose and city views.
The graphic uses attributable property value; select a column or named
asset to inspect value, debt, cash and decision information.
Open asset returns to the working asset details and editing controls.

SAVE PORTFOLIO EDITS
Portfolio data stays in the current tab and is lost on reload or closing.
Before leaving, use Export > Save editable backup to download a JSON file.
Use Export > Restore a backup to continue from that saved file.
The portfolio also exports readable HTML snapshots and CSV registers.
Property-record valuation history and locally uploaded files are separate from that backup.

SERVICES
Choose a service, add the property and scope, and save a request draft.
Requests can be edited and downloaded. They are not sent automatically.
Saved opportunities and request drafts use browser storage where available.

RESEARCH & INTELLIGENCE
The navigation opens the approved external destination directly:
https://screen-magic-tool-01.lovable.app/
Internet access is required for that destination.
The original local sample PDFs remain in the reports folder.

MOTION
Main navigation uses a brief full-screen transition.
Portfolio exploration and opportunity dossiers are opened by the user.
The Motion control in the header reduces animation; system reduced-motion
preferences are also respected. Full-screen views have visible close controls
and support Escape on a keyboard.

HOSTING
This is a static HTML/CSS/JavaScript website. No build step is required.
Upload the folder contents with index.html at the website root and retain
the relative asset paths. No database, user authentication, live financial
feed, order execution or message-sending service is connected.

DATA AND IMAGERY
All sample opportunities, portfolio entries and report PDFs are illustrative.
Photographs illustrate asset categories and are not verified photographs
of the displayed opportunities or family holdings.
The portfolio model uses entered ownership shares and cash assumptions.
Methodology and calculation limitations are available within My Portfolio.

EDITION 15 — ASSET COMMAND CENTRE (INDIASSETZ-INSPIRED)
- My Portfolio > Property records opens a searchable asset register.
- Each asset has Overview, Valuation, Documents and Services & decisions.
- Overview shows ownership, authority, estimated equity, rent, debt and four concise review points.
- Valuation history accepts dated, source-labelled observations and shows a simple chart.
  Historical observations do not automatically change the current portfolio value.
- Documents: optional local PDF/image uploads up to 8 MB stored in browser IndexedDB.
  Documents are NOT backed up in the existing portfolio JSON export and are NOT synced.
  Never use real client-sensitive documents in this demonstration.
- Services can be started from an asset record with asset name and city pre-filled.
- Requests can be self-tracked as Draft, To review, In progress or Completed.
  These are local statuses, not proof that any provider has received or performed work.
- Services page has a direct entry to Property records.
- Research link and existing Opportunities, portfolio risk, cash and scenarios are retained.

IMPORTANT
This is a local prototype, not an authenticated client platform. For production,
add user authentication, role-based access, encrypted cloud document storage,
permissioned advisor workflow, audit logs and approved valuation data sources.
Portfolio holdings remain session-only; export their JSON backup before leaving.
Valuation observations use localStorage; documents use IndexedDB and are device-specific.
